# بوت تليجرام لتحميل الفيديوهات والصور

بوت يقوم بتحميل الفيديوهات والصور من تيك توك، يوتيوب، تويتر/X، إنستغرام وأي منصة أخرى يدعمها `yt-dlp`، عند إرسال رابط له في محادثة خاصة أو داخل مجموعة.

## المميزات
- يعمل في المحادثات الخاصة وفي المجموعات.
- يكتشف الروابط تلقائيًا داخل أي رسالة، ويدعم أكثر من رابط في نفس الرسالة.
- يدعم الفيديو والصور.
- يرسل نص المنشور الأصلي (الناشر + الوصف) مع الفيديو، ورابط قابل للنقر بعنوان "رابط الفيديو".
- زر 🔊 لتحميل الصوت فقط (MP3) من نفس الفيديو.
- رسالة تقدّم التحميل تتحدث مباشرة (نسبة الإنجاز + السرعة + الوقت المتبقي).
- تخزين مؤقت (Cache): لو طُلب نفس الرابط مرة أخرى يُعاد إرساله فورًا دون إعادة تحميل.
- حد أقصى للتحميلات المتزامنة لحماية السيرفر من الضغط الزائد.
- أمر `/help` يشرح طريقة الاستخدام.
- 🛠 لوحة تحكم للمشرف: تغيير رسالة الترحيب و`/help` وإضافة أزرار مخصصة دون تعديل الكود.
- تنظيف تلقائي للملفات بعد الإرسال.

## 1) إنشاء البوت والحصول على التوكن
1. افتح تليجرام وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات لتسمية البوت.
3. سيعطيك BotFather توكن مثل: `123456789:ABCdefGhIJKlmNoPQRstuVWXyz`. احتفظ به.

## 2) تفعيل عمل البوت داخل المجموعات (مهم جدًا)
افتراضيًا، بوتات تليجرام لا "ترى" كل الرسائل داخل المجموعة إلا إذا:
- تم تعيينها كمشرف (Admin) في المجموعة، **أو**
- تم إيقاف "Privacy Mode" من BotFather:
  1. أرسل لـ `@BotFather`: `/mybots`
  2. اختر بوتك ← `Bot Settings` ← `Group Privacy` ← `Turn off`

بعد ذلك أضف البوت إلى المجموعة، وسيقوم بقراءة كل رسالة يرسلها الأعضاء ويحمّل أي رابط يجده فيها.

## 3) لوحة التحكم للمشرف (تغيير الرسائل والأزرار بدون تعديل الكود)

1. احصل على معرّف تليجرام الخاص بك (Telegram User ID) عبر إرسال أي رسالة للبوت `@userinfobot`.
2. في Railway، أضف متغير بيئة جديد:
   - `ADMIN_IDS` = المعرّف الرقمي الخاص بك (لأكثر من مشرف، افصل بينهم بفاصلة: `123456,987654`)
3. بعدها راسل بوتك مباشرة بهذه الأوامر:

| الأمر | الوظيفة |
|---|---|
| `/admin` | عرض كل أوامر التحكم |
| `/setwelcome <النص>` | تغيير رسالة `/start` |
| `/resetwelcome` | استعادة رسالة الترحيب الافتراضية |
| `/sethelp <النص>` | تغيير رسالة `/help` |
| `/resethelp` | استعادة رسالة `/help` الافتراضية |
| `/addbutton welcome "النص" https://رابط` | إضافة زر لرسالة الترحيب |
| `/addbutton help "النص" https://رابط` | إضافة زر لرسالة `/help` |
| `/removebuttons welcome` أو `help` | حذف كل الأزرار |
| `/listbuttons welcome` أو `help` | عرض الأزرار الحالية |
| `/addcmd <اسم> <النص>` | إنشاء أمر مخصص جديد يردّ عليه البوت تلقائيًا |
| `/removecmd <اسم>` | حذف أمر مخصص |
| `/listcmds` | عرض كل الأوامر المخصصة الحالية |

النصوص تدعم تنسيق **ماركدون**: `*عريض*`، `_مائل_`، `[نص](رابط)`.

مثال:
```
/setwelcome مرحبًا بك! 🎬 أرسل رابط أي فيديو وسأحمّله لك فورًا.
/addbutton welcome "قناتنا على تيليجرام" https://t.me/your_channel
/addcmd rules يرجى الالتزام بقوانين المجموعة والاحترام المتبادل.
```
بعدها، أي شخص يرسل `/rules` في المجموعة أو الخاص، البوت يرد عليه تلقائيًا بالنص اللي حددته.

⚠️ **ملاحظة مهمة عن الاستمرارية:** يتم حفظ هذه الإعدادات في ملف داخل حاوية Railway. هذا الملف **يبقى بين إعادة التشغيل العادية، لكنه يُمسح عند كل عملية نشر جديدة (Redeploy)** لأن Railway ينشئ حاوية جديدة من الصفر. إذا أردت أن تبقى إعداداتك دائمة حتى بعد كل تحديث للكود، أضف **Volume** من إعدادات الخدمة في Railway واربطه بمسار المشروع، أو اسأل لاحقًا وسنجهز الكود لاستخدام قاعدة بيانات بسيطة بدلاً من الملف.

## 4) التشغيل محليًا (اختياري للتجربة)
```bash
python -m venv venv
source venv/bin/activate   # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
export BOT_TOKEN="التوكن_الخاص_بك"   # على ويندوز: set BOT_TOKEN=...
python bot.py
```

## 5) رفع المشروع على GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
> لا ترفع ملف `.env` أو التوكن مباشرة في الكود — استخدم متغيرات البيئة كما هو موضح تاليًا.

## 6) النشر على Railway
1. اذهب إلى https://railway.app وسجّل الدخول (يمكن عبر GitHub).
2. اضغط **New Project ← Deploy from GitHub repo** واختر المستودع الذي رفعته.
3. بعد إنشاء المشروع، اذهب إلى تبويب **Variables** وأضف:
   - `BOT_TOKEN` = التوكن الذي حصلت عليه من BotFather
4. Railway سيكتشف تلقائيًا أنه مشروع بايثون وسيستخدم `Procfile` لتشغيل الأمر `python bot.py`.
5. بعد اكتمال النشر، افتح تبويب **Deployments ← Logs** للتأكد من ظهور رسالة "Bot is starting...".
6. جرّب إرسال رابط للبوت في الخاص، ثم أضفه لمجموعة وجرّب هناك.

## ملاحظات مهمة
- **حد الحجم:** بوتات تليجرام العادية (عبر Bot API السحابي) لا يمكنها إرسال ملفات أكبر من 50 ميجابايت تقريبًا. الفيديوهات الأكبر من ذلك سيتم رفض إرسالها. لتجاوز هذا الحد تحتاج تشغيل [Local Bot API Server](https://github.com/tdlib/telegram-bot-api) الخاص بك بدلاً من الخادم السحابي.
- **حقوق الملكية:** تأكد من احترام شروط استخدام المنصات وحقوق الملكية الفكرية عند تحميل ومشاركة المحتوى؛ استخدم هذا البوت لأغراض شخصية ومشروعة فقط.
- **yt-dlp يحتاج تحديث دوري:** المنصات تغيّر واجهاتها بين حين وآخر، لذا حدّث مكتبة `yt-dlp` بشكل دوري (`pip install -U yt-dlp`) إن لاحظت توقف التحميل من منصة معينة.
